# 🤖 AI Chat Assistant

A modern AI chat application similar to ChatGPT with multiple AI models, tools, and social media downloaders.

## Features

- 🎨 **Modern UI** - ChatGPT-inspired design with dark theme
- 🤖 **Multiple AI Models** - 9 AI models including ChatGPT, Gemini, Claude Opus, and more
- 🖼️ **AI Image Generation** - Generate images with AI
- 🛠️ **Tools** - Cek Nomor, OTP Generator, Screenshot Web, Translate
- 📥 **Social Media Downloaders** - Instagram, Facebook, TikTok, Twitter, YouTube, Spotify
- 🔐 **Authentication System** - Login/Register with Google support
- 👨‍💼 **Admin Dashboard** - Full user management capabilities
- 💻 **Code Highlighting** - VS Code-style code blocks
- 📱 **Responsive Design** - Works on all devices

## Installation

1. Clone or download the project
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm start
   ```
4. Open http://localhost:3000 in your browser
